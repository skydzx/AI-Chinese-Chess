# AIChineseChess 设计规范

**项目**: AIChineseChess - 中国象棋AI人机对弈平台
**版本**: 1.0
**日期**: 2026-03-13
**状态**: 设计评审中

---

## 1. 项目概述

### 1.1 目标
构建一个完整的中国象棋人机对弈平台，采用AlphaZero风格的深度学习+MCTS方案，让用户可以与AI进行对弈、复盘、学习。

### 1.2 技术方案
- **核心算法**: AlphaZero风格 (神经网络 + MCTS蒙特卡洛树搜索)
- **神经网络**: 小型ResNet (8层, 128通道) - 适配4G显存
- **训练方式**: 自对弈强化学习 + 人类棋谱微调
- **目标水平**: 入门级（略强于初学者）

## 3. 功能模块

### 3.1 对弈模块
- **人机对弈**: 用户 vs AI，支持不同难度级别
- **人人對弈**: 双人对弈本地
- **AI vs AI**: 观察AI自我对弈学习
- **走法提示**: 显示AI推荐走法
- **悔棋功能**: 支持多步悔棋
- **认输/求和**: 正常对弈流程

### 3.2 棋谱管理
- **棋谱格式**: 支持XQF、PGN、EXOH格式导入导出
- **棋谱浏览**: 逐步查看历史局面
- **分支变化**: 支持查看不同变着
- **棋谱收藏**: 收藏重要棋谱
- **在线棋谱**: 从ChessDB等获取棋谱

### 3.3 局面分析
- **实时分析**: 显示当前局面评估
- **多步分析**: 预设深度分析
- **走法排序**: 按优劣排序所有合法走法
- **局面评分**: 显示子力分+位置分

### 3.4 开局/残局库
- **开局库**: 集成开源中国象棋开局库（至少5万局）
- **残局库**: 基础残局库（马兵类、炮兵类等）
- **库显示**: 指示当前是否在库中

### 3.5 水平测试
- **开局测试**: 考察开局选择
- **中局测试**: 战术组合判断
- **残局测试**: 残局定式掌握
- **评分系统**: 给出业余等级评估

## 4. 神经网络设计

### 4.1 输入编码 (56通道 = 14通道 × 4步)
| 通道 | 描述 |
|------|------|
| 1-7 | 红方：帅/仕/相/车/马/炮/兵 |
| 8-14 | 黑方：将/士/象/车/马/炮/卒 |
| 15-28 | 历史1步 (同上14通道) |
| 29-42 | 历史2步 (同上14通道) |
| 43-56 | 历史3步 (同上14通道) |

注：每步历史记录该步之前的棋盘状态，用于判断送子、捉子等战术。

### 4.2 网络结构
```
Input: [batch, 14, 10, 9]
  ↓
Conv2d(14, 128, 3x3, padding=1) + BatchNorm + ReLU
  ↓
Residual Block × 8:
  - Conv2d(128, 128, 3x3, padding=1)
  - BatchNorm + ReLU
  - Conv2d(128, 128, 3x3, padding=1)
  - BatchNorm + Add + ReLU
  ↓
Policy Head:
  - Conv2d(128, 32, 1x1) + ReLU
  - Flatten → Linear(32×10×9, 2098) → Softmax
  ↓
Value Head:
  - Conv2d(128, 1, 1x1) + ReLU
  - Flatten → Linear(10×9, 64) + ReLU
  - Linear(64, 1) → Tanh
```

### 4.3 训练配置
- **批次大小**: 128 (适配4G显存)
- **学习率**: 0.001，余弦衰减
- **优化器**: Adam
- **损失权重**: 策略损失1.0 + 价值损失1.0
- **自对弈**: 每轮1000局
- **MCTS模拟**: 500次/步
- **训练轮数**: 100轮（可调整）

## 10. 风险与应对

| 风险 | 应对方案 |
|------|----------|
| 显存不足 | 减少batch size / 减少网络层数 |
| 训练过慢 | 使用混合精度训练 / 减少模拟次数 |
| 水平不足 | 增加训练量 / 引入开局库辅助 |
| 界面卡顿 | 多线程处理AI计算 |
