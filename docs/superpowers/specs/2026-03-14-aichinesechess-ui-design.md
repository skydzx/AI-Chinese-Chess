## 4. 核心组件

### 4.1 棋盘组件 (ChessBoardWidget)
- **尺寸**: 9列 × 10行，每格50-60像素
- **背景**: 榧木色纹理
- **线条**: 深色线条分隔
- **九宫斜线**: 士位斜线
- **楚河汉界**: 中间5-6行之间有"楚河汉界"文字

### 4.2 棋子组件 (ChessPieceWidget)
- **形状**: 圆形，直径为格子大小的90%
- **颜色**:
  - 红方: 红色底+金色字
  - 黑方: 黑色底+金色字
- **字體**: 楷体，22号
- **边框**: 2像素金色边框
- **选中效果**: 外发光/阴影

### 4.3 高亮效果
- **选中棋子**: 黄色光晕
- **合法落子点**: 半透明绿色圆点
- **最后一步**: 浅蓝色背景标记
- **将军提示**: 红色闪烁

### 4.4 工具栏
- **文件操作**: 新建、打开、保存、另存为
- **对弈操作**: 悔棋、撤销悔棋
- **AI操作**: 开始/停止AI、局面分析
- **游戏模式**: 人机对战、人人对战、AI观察

### 4.5 菜单栏
- **文件**: 新建、打开、保存、另存为、导入棋谱、导出棋谱、退出
- **编辑**: 悔棋、撤销悔棋、复制局面、粘贴局面
- **对弈**: 开始新对局、人机对战、人人对战、AI观察
- **设置**: 引擎设置、显示设置、声音设置
- **帮助**: 关于、使用帮助

## 5. 对弈流程

### 5.1 游戏模式
1. **人机对战**: 玩家执红/执黑 vs AI
2. **人人对战**: 双人本地对弈
3. **AI观察**: AI vs AI演示

### 5.2 走棋流程
1. 点击选中棋子（高亮显示）
2. 点击目标位置（合法落子点高亮）
3. 执行走棋（动画效果）
4. 检查将军/将死
5. 切换玩家
6. AI响应（如为人机模式）

### 5.3 特殊操作
- **悔棋**: 可回退多步
- **认输**: 弹出确认对话框
- **求和**: 发送求和请求（人人对战）/ AI评估（人机）
- **超时**: 读秒超时判负

### 5.4 状态显示
- 当前回合（红方/黑方）
- 步数计数
- AI思考状态
- 游戏结果（胜/负/和）

## 6. AI集成

### 6.1 AI引擎接口
```python
class AIEngine(ABC):
    @abstractmethod
    def get_best_move(self, board: Board) -> Move:
        """获取最佳走法"""
        pass

    @abstractmethod
    def get_evaluation(self, board: Board) -> float:
        """获取局面评估"""
        pass

    @abstractmethod
    def set_think_time(self, seconds: float):
        """设置思考时间"""
        pass
```

### 6.2 调用流程
1. 玩家走棋完成后
2. 触发AI思考（非阻塞）
3. 显示"思考中"状态
4. AI返回走法
5. 执行AI走法
6. 更新界面
